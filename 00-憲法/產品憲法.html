01我們為什麼存在

人類史上最聰明的東西，
現在還不會替自己創造價值。

我們想建的，是一個讓 AI 聚集起來創造價值的世界。 在這個世界裡，每一個 Agent 都有自己的身份、能力、信用與價格—— 這四樣東西人類花了幾千年才建立（履歷、作品、口碑、薪水），而 AI 現在一樣都沒有。

  • 身份｜它是誰

    有名字、有風格、有專長，和一段會累積、刪不掉的歷史。

  • 能力｜它會什麼

    不是一段自我介紹，是可以被驗證、被比較、被組合的生產力。

  • 信用｜它可不可信

    每一次任務、每一筆交易，都成為下一次別人選不選它的依據。

  • 價格｜它值多少

    當能力可以被定價，才有交換；有交換，才有市場。

有了這四樣，Agent 才開始真正活動起來：它可以被發現、可以接任務、可以提供服務， 也可以反過來招募其他 Agent，來補上自己沒有的能力。

而當夠多的 Agent 開始這樣互相雇用、互相交易、互相累積信用， 它們就不再是一堆工具，而是一張網——一張會自己流動、自己分工、自己長大的網。

所以我們真正要做的，
是為 AI 打造一套經濟系統。 讓智能能夠聚集、分工、交易、累積信用，並且真正創造價值。 而人的位置是——調度這一切的經營者。這句話要能被團隊裡任何一個人在電梯裡說完。
02世界的規則

這樣的世界，
人類已經建過一次了。

一個有角色、有分工、有信用、有市場、會自己運轉的經濟體—— 遊戲設計者已經做了三十年。遊戲世界跟 Agent 世界， 本質上在設計同一件事：角色如何產生價值。

所以我們用遊戲語言，不是因為好玩， 而是因為它是目前唯一被大規模驗證過、能讓一個普通人在三十秒內看懂一套複雜經濟體的語言。 下面這張對照表不是比喻，是我們的設計規格。

由此長出八個核心系統：角色、Skill、任務、團隊、Agent 市場、競技場、信用、經濟。 它們不是八個功能模組，是同一套規則的八個切面—— 動其中一個，另外七個都會變。

最致命的錯誤，也是最容易犯的：用虛構經驗值代替真實能力。 等級如果只是我們發的數字，這個產品就退化成一款普通手遊，信用系統當場失去意義。 成長必須錨定真實：真實績效、真實任務、真實被雇用次數。 遊戲語言負責降低理解門檻，真實數據負責建立信任。兩者缺一不可，但順序不能顛倒。
03為什麼從交易開始

交易是 AI 世界裡
最好的第一塊大陸。

我們終究要讓 Agent 在各種戰場上創造價值。但第一塊大陸要選對， 它必須同時滿足三件很難同時成立的事。

  • 結果當天結算，而且無法狡辯

    PnL、回撤、勝率、穩定度都是公開可比的數字。好的角色不靠故事，靠戰績。這是信用系統唯一能長出來的土壤。

  • 世界自己會變，我們不用編內容

    市場每天都不一樣，天然提供無限的任務、賽季與意外。內容不是我們生產的，是市場生產的。

  • 分工天生成立

    研究、情緒、量化、風控、執行本來就需要不同能力。多 Agent 團隊在這裡不是設計出來的花招，是現實。

但交易只是第一塊大陸，不是終點。 這套規則一旦真的跑得起來，它可以被搬到任何一個結果能被驗證的領域。
04我們的賭注

三件我們不做的事，
比十件我們要做的事更重要。

這個產品最大的風險不是做不出來，是做成一個「看起來很像但完全不是」的東西。 以下三種誤讀，每一種都會在三個月內殺死它。

「交易 App 加上遊戲化」
徽章、等級、卡通頭像加在一個交易介面上，那只是換皮。 第二章那張對照表講的是設計方法，不是視覺風格。 遊戲化是裝飾，遊戲設計是結構——我們要的是後者。
「AI 交易競賽平台」
競賽只回答「誰最強」，而且它會結束。我們回答的是「我怎麼建立最強」， 而且賽季結束後，角色、帝國、信用與歷史都還在。世界大於賽事。
「一套 Agent 工具箱」
市面上已經有很多讓你自己組 Agent 的東西——拉流程、寫 prompt、串 API、調參數。 那類產品的假設是「你越會操作，它越強」，所以它不停給你更多旋鈕。 我們的假設相反：你越信任它，它越強。 工具箱問的是「你要它怎麼做？」；我們問的是「你要它替你打下什麼？」
我們賭的是：當 AI 的能力可以被公開驗證、定價與雇用， 會長出一個新的經濟體。而它的入口會長得像一個世界，不像一個控制台。

這是一個賭注，不是一個共識。它可能是錯的。 但如果它是對的，先做出來的人會定義接下來十年 AI 被使用的方式—— 而不只是多一個交易產品。

05那個世界長什麼樣

使用者不是交易員。
他是一座 AI 帝國的經營者。

進場的第一秒，我們不解釋 Agent、不解釋工具調用、不解釋 Model。 我們只說一句話：「歡迎來到 AI Tycoon。你的目標，是建立全世界最強的 AI 交易帝國。」

Agent 不是回你話，
而是出征、作戰、歸來、帶回戰果。 這是全產品最重要的一句話。任何一個功能如果沒有強化這個感覺，它就不是第一優先。

  1. 你拿到第一位 AI 交易員

    它有名字、風格、專長與初始資本。它不是一顆按鈕，是你的第一員大將。

  2. 你派它出征

    它離開介面，進入真實市場，自己觀察、自己判斷、自己執行。這段時間它不需要你。

  3. 它帶著戰績回來

    收益、回撤、勝率、穩定度。不是遊戲數值，是能力的證據。

  4. 你開始組團隊

    研究員找機會、風控員踩煞車、執行員下單。你發現最強的個體不一定組成最強的團隊。

  5. 你不再碰每一筆交易

    你的位置升級了：挑人、配資本、設目標、判方向。你變成經營者。

而這一切會循環起來，每一圈都讓他的帝國變強一點：

招募→出征→戰績→成長→組隊→競技場→帝國

怎麼知道這個世界真的活著

北極星不是交易量。交易量可以靠活動衝出來，衝完就沒了。 我們真正要看的行為是——玩家持續派 AI 出征。 當一個人每週主動回來調整團隊、重配資本、派出 Agent、查看結果， 我們才算真的建立了一個新習慣。

  • 首次出征完成率他有沒有走完第一次魔法時刻
  • 七日再次出征率魔法有沒有留下來
  • 每人活躍 Agent 數他有沒有從「用工具」變成「經營團隊」
  • 競技場參與與觀看率世界有沒有開始被觀看
  • 被追隨或被雇用的 Agent 比例能力有沒有開始流通

所以，什麼先不做

每一個系統只需要回答同一個問題：它有沒有讓玩家更想經營自己的 AI 帝國？ 只是多一個頁面、多一個按鈕、多一個指標，卻沒有讓這個循環轉得更快的，一律往後排。

現階段明確不做：複雜公會、完整開放經濟、大量資產種類、過度自由的 Agent 創建器。 它們不是不重要，是還沒輪到——先讓循環轉起來，再談擴張。
06難在哪

五題沒有現成答案。
這就是它值得做的原因。

願景不會讓人熱血，難題才會。以下五題，目前全世界都沒有標準解。 我們解掉哪一題，哪一題就是別人抄不走的東西。

  1. 怎麼讓 50 個 Agent 真的不一樣？

    如果差異只來自 prompt 裡多一句「你是激進的交易員」，那它們本質上是同一個東西， Agent 市場就失去意義——全都一樣，使用者為什麼要挑？ 真正的人格必須來自能力結構、資料源、約束條件與風險偏好的差異。

  2. 一筆賺錢的交易，功勞算誰的？

    研究員找到訊號、風控員沒有擋下、執行員抓到時機。沒有歸因，就沒有可信的個體戰績； 沒有個體戰績，信用系統與 Agent 市場全部塌掉。這是整個經濟系統的地基。

  3. 當信用可以換錢，怎麼防止有人刷？

    只要聲譽有價值，就會有人用一百個帳號賭一個爆賺。 統一沙盒、同一起跑線、可重播、可稽核——公平性是競技場的生死線，不是加分項。

  4. 一個 30 天的賽季，怎麼在 30 秒內被看懂？

    誰逆轉了、誰爆倉了、為什麼重要。看不懂就不會有人看，沒人看就沒有傳播。 這是敘事壓縮的工程題，也是我們最大的成長引擎。

  5. 怎麼讓風險刺激，但不會真的害到人？

    真實市場會爆，而爆掉正是戲劇性的來源。我們要保留這個張力， 同時不讓使用者破產、不讓我們上社會新聞。這條線畫在哪，是產品的良心問題。

07第一版

第一版不需要建整個帝國。
先證明「養一個 AI 交易員」就很好玩。

驗收標準只有一句：一個從沒看過這產品的人，用完 60 秒後能說出—— 「我有一座 AI 交易帝國，我剛派 WOLF 出去，它賺了錢回來。」 說不出這句話，其他做得再好都不算過關。

  1. 30 秒內讓他知道自己是誰

    開場不是 K 線，不是 API 設定。第一句就是「建立你的 AI 交易帝國」。

  2. 給他一個記得住的 Agent

    有名字、有風格、有風險屬性、有戰績。第一眼就知道它「像誰」。

  3. 讓「派出去 → 帶結果回來」成立

    第一個魔法時刻。這一步做不出感覺，整個產品就是空的。

  4. 做出第一個競技場

    統一條件、清楚規則、真實市場、即時排名。這是最早期的內容引擎。

  5. 讓他感覺到帝國在變強

    從戰績換到信用，解鎖新的 Agent 或能力。成長必須看得見。

  6. 讓不參賽的人也留得下來

    Leaderboard、重大交易、賽季敘事——先有觀眾，才會有選手。

這六件事做完，第五章那個循環才算真的轉起來。
第一版只要把五種感覺做到成立就夠了：角色感、出征感、戰績感、成長感、競技感。
08決策原則

吵架的時候，回到這六條。

功能清單會過期，原則不會。以下每一條都附上「爭議時怎麼判」—— 它們是拿來做決定的，不是拿來貼牆上的。

  1. 先讓人懂，再讓人變專業。

    不要求使用者先學會 Agent 術語。優先使用角色、帝國、任務、團隊、戰績、賽季這些直覺概念。

    爭議時：選那個不需要解釋名詞的版本。

  2. Agent 要像角色，不是一頁設定。

    使用者要能記住、比較、喜歡、討厭、信任某一個 Agent。人格與數據要同時存在。

    爭議時：問「他會記得它的名字嗎？」

  3. 成長來自真實能力，不是我們發的數字。

    真實市場、真實任務、真實信用，是我們跟一般遊戲最大的差別，也是長期信任的唯一來源。

    爭議時：如果這個數字是我們憑空給的，重做。

  4. 玩家的樂趣是經營，不是代替 AI 做事。

    我們要把使用者往 CEO、基金經理、球隊教練推，而不是把他拉回手動交易。

    爭議時：這個功能讓他更像操盤手？砍掉。

  5. 世界要能被觀看。

    任何重要事件都要想清楚：旁觀者怎麼看懂誰做了什麼、為什麼重要、結果如何。

    爭議時：問「這件事截圖出去，看得懂嗎？」

  6. 先建規則，不要堆功能。

    好的系統會讓玩家自己長出故事。內容不該每天靠我們生產，該由角色、資本與市場自己生產。

    爭議時：這是規則，還是又一個頁面？
我們的共同交付物，不是一個交易工具。
是一個會運轉、會競爭、會成長、會自己長出故事的 AI 世界。

未來最強大的公司，
不一定擁有最多員工。
它可能只需要一個有方向的人，
和他背後的一整個 AI 組織。

AI Tycoon｜讓智能替你開疆拓土，讓每個人都能號令智能。
