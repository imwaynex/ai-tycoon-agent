# AI Tycoon（ai-tycoon-agent）

OKX AI Tycoon 遊戲化產品工作區與短征原型。

## 目錄

| 路徑 | 內容 |
|------|------|
| `00-憲法/` | 產品憲法 |
| `01-範圍/` | 範圍表、驗收句 |
| `02-系統規則/` | 出征契約與規則補丁 |
| `03-世界敘事/` | 文案槽 |
| `04-體驗設計/` | 動線／IA／mobile 框 |
| `05-工程/short-raid-proto/` | 可運行短征原型（含 D18） |
| `06-競品與對照/` | 決策與對照 |
| `99-交接/` | 任務交接與現況看板 |

## 跑原型

```bash
cd 05-工程/short-raid-proto
npm i
npm test
npm run dev
```

舊倉 `imwaynex/ai-tycoon` 為成長薄片線，與本倉分開。
