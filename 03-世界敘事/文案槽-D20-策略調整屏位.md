## 3｜大將側「改打法」（原派出前 NL）

入口：大將屏次級／薄層 **改打法**（勿開參數工廠）。

| 槽 | 文案 |
|----|------|
| 入口 | 跟 {agent_name} 交代怎麼打。派出前在這裡調。 |
| 界內 | 收到。{nl_accepted} 仍在它會的範圍內。 |
| 改寫回界 | 超出它會的了。已收束：{nl_rewritten}。 |
| 擋下 | 這步做不到——不是不肯，是不能超。收一收再試。 |
| 反工具箱 | 這裡是交代大將，不是改設定面板。 |
| 調完導出 | 打法已定。去選出征多久，再派出。 |

派出頁／戰報頁／出征中：**整段無入口**。

## 6｜自檢（對 D20 三點）

1. 改打法只在大將／角色側  
2. 派出頁只選期間，無改打法  
3. 歸來／撤回後能走到「改打法 → 再派」，不是選週期邊選邊調  

D18 其餘：撤回結算、無紀錄於派出、戰報禁調、無「模擬」字——仍守。
