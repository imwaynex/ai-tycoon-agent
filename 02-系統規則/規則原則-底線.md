# 系統規則底線（長期）
負責人：Tycoon 系統規則  
狀態：定稿原則（來自產品憲法；範圍細節仍待 Wayne）  
更新：2026-09-15

1. 成長必須錨定真實績效／真實任務／真實被雇用；禁止虛構 XP 當核心成長。爭議時：若數字是憑空發的，重做。
2. 八系統（角色、Skill、任務、團隊、Agent 市場、競技場、信用、經濟）是同一套規則的切面；改一個要想連動。
3. Agent 差異必須來自能力結構／資料源／約束／風險偏好，不靠 prompt 自稱。
4. 歸因要有最低可稽核方案（見 BattleResult attribution 欄位）。
5. 公平性（統一沙盒、可重播、可稽核）不是加分項。
6. 風險刺激但不得真害人；真實資金／合規上限須 Wayne 裁定。
7. 現階段不做：複雜公會、完整開放經濟、大量資產、過度自由 Agent 創建器。
