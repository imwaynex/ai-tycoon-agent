# 成長薄片｜實作基準
負責人：Tycoon 系統規則  
狀態：**實作基準**（對齊 `01-範圍/成長薄片-產品確認.md`）  
更新：2026-09-15  
前提：出征閉環實作基準仍有效；本切片疊加，不改出征主路徑

## 切片邊界
### 必做
1. 同一 `agent_id`（WOLF）至少兩筆已 settle、可進正式牆的 `BattleResult` 可對照
2. 對照欄位：`realized_pnl`、`return_pct`、`max_drawdown`（可加 `trade_count`）
3. 成長話術／UI 只錨真實績效差異；禁止 XP／等級／徽章／信用分
4. 零次出征＝戰績牆空態（強制落地；同出征閉環 §5）
5. 模擬盤標紅維持

### 不做（寫死）
- 信用、定價、雇用、被跟隨
- 虛構 XP／等級／徽章主成長
- 競技榜、賽季、訂閱、ASP（B 刀）
- 多 Agent、第二預置角色
- K 線、手動下單、取消、真實資金
- 把兩次戰績壓成單一「成長分／實力分」

---

## 1) 對照輸入
### 合格戰績
- 來源：本帝國、該 `agent_id`、玩家出征後引擎 settle 的 `BattleResult`
- 須可進正式戰績牆（重放一致；非失格）
- `status=completed` **或** 失敗態：皆可進牆與對照（失敗也是真實績效）；差異計算仍用數值欄位

### 選哪兩筆
- 預設：同一 `agent_id` **最近兩筆**正式牆紀錄（`settled_at` 新→舊）
- 記為 `prev`（較舊）、`curr`（較新／這次）
- 僅一筆：不開對照 UI；走敘事 G0
- 零筆：空牆；走槽⑥／G4

### 禁止
- 開場預置 mock 當 `prev`／`curr`
- Agent 自報、非引擎結果、跨 Agent 混比（本切片只比 WOLF 自己）

---

## 2) 差異怎麼算
欄位對欄位，引擎算；敘事不發明公式。

| delta 欄位 | 定義 |
|------------|------|
| `delta_realized_pnl` | `curr.realized_pnl - prev.realized_pnl` |
| `delta_return_pct` | `curr.return_pct - prev.return_pct` |
| `delta_max_drawdown` | `curr.max_drawdown - prev.max_drawdown`（回撤為負向風險；**更小的絕對回撤較好**，見下） |
| `delta_trade_count` | 可選：`curr.trade_count - prev.trade_count`（只展示，不參與更好／更差判定） |

單位／幣種須與 BattleResult 一致（`sandbox_USD`）。

### 可選語氣 G2／G3（更好／更差）
- **非必顯**；若顯，必須同時顯示三個（或至少 pnl＋return＋drawdown）數字差異，禁止只喊「變強了」
- 判定主鍵（公開、寫死）：`delta_return_pct`
  - `> 0` → 可套 G2（更好）
  - `< 0` → 可套 G3（更差）
  - `= 0` → 不套 G2／G3；只顯示 G1 數字對照
- 回撤輔助說明（不翻轉主鍵）：若 `|curr.max_drawdown| < |prev.max_drawdown|`，文案可註「回撤收斂」，**不可**單獨據此改 G2／G3
- 禁止黑箱加權把多欄混成單一成長分

## 3) GrowthCompare 物件（建議必填）
```
compare_id
agent_id
empire_id
prev_result_id
curr_result_id
prev_* / curr_*（可講欄位快照）
delta_realized_pnl
delta_return_pct
delta_max_drawdown
delta_trade_count? 
verdict: better | worse | flat | none
  — better/worse 僅當套用主鍵規則；僅一筆或未對照＝none
created_at
```

`verdict=none`：零筆、一筆、或產品選擇不顯示 G2／G3。

---

## 4) 空牆紅線（本切片必須落地）
- 零次正式 settle → 戰績牆空態；禁止預置假歷史
- 有 ≥1 筆後才顯示牆內容
- 有 ≥2 筆後才顯示成長對照

---

## 5) 可講／禁講
### 可講
- prev／curr 的可講 BattleResult 欄位
- 三個 delta（＋可選 trade_count）
- 可選 G2／G3（須附數字）

### 禁講
- XP、等級、徽章、信用、聲譽升級
- 無對照的「變強了」
- 榜單／訂閱／圍觀語氣
- score／競技名次

---

## 標紅未定（不擋本切片）
- 對照掛在歸來屏／牆／角色卡的最終版位（體驗定）
- 是否預設顯示 G2／G3 或僅 G1（體驗／產品可裁；規則允許皆可）
- `trade_count` 是否進主對照列

## 驗收對齊
兩次 settle 後，玩家能用真實數字指出好／差在哪；仍想再派；截圖不是發經驗值。
