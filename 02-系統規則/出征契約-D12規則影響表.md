## 2. D12-2 每征可換期間

### 2.1 現況對照（D11）

| 點 | D11 現況 |
|---|---|
| 欄位 | `time_window_type`、`planned_duration` 已在 32 必填 |
| 數值 | 秒數後補；短征允許壓縮模擬 |
| 再派 | `returned` → 新契約；非改寫舊約 |
| 寫死 | 未寫「帝國／Agent 級鎖死單一期間」禁則；亦未寫「每征可異」明示 |

### 2.2 影響

- 期間屬**單次契約**實例欄位，非帝國設定、非 Agent 永久屬性。
- 同 `agent_id` 多次出征 → 各約可帶不同 `time_window_type`／`planned_duration`。
- **禁止**帝國級或 Agent 級鎖死單一固定期間（違反 D12-2 驗收句）。
- 派出前（`ready`）：可選／重設本約期間。
- 進入 `in_field` 後：本契約期間不可熱改（與 `strategy_version` 派出後不可熱改一致）。
- 再派＝新約 → 新約可重新選期間。

### 2.3 結算閘

| 檢查 | 要點 |
|---|---|
| 存在 | 本契約 `time_window_type` 非空；`planned_duration` 欄位存在（數值後補後須合法） |
| 合法 | 本輪至少支援固定時長；值落在產品後補之合法集合 |
| 重播 | 用**本契約**時長／時窗鍵重播；不得改用他約或帝國預設覆寫 |
| 壓縮 | 壓縮／加速模擬**不得改寫**已結算契約之 `planned_duration`／`time_window_type` 欄位值；僅影響體驗時鐘，戰報仍標模擬源 |

### 2.4 對 D11 lock 建議

| 動作 | 判定 |
|---|---|
| 改 32 必填名單 | **否** |
| 改寫死旗標 | **否** |
| 擴展規格說明 | **是**（建議補進 lock 規格附錄或另檔；待 Mack 准後併入） |
| 待 Mack 裁定 | 無（本項不需改 lock 結構） |

### 2.5 工程注意

- UI／API：出征席派出前暴露期間選擇；禁止寫死單一全局期間。
- 儲存：期間存於契約列，勿存成 Agent 唯一期間欄再覆寫歷史。
- 壓縮模擬與計劃時長分離：體驗加速 ≠ 改欄位值。

## 3. D12-1 職業＝Skill

### 3.1 現況對照（D11）

| 點 | D11 現況 |
|---|---|
| `strategy_version` | 必填；派出後不可熱改本約綁定 |
| `constraint_snapshot` | 必填；派出後非空（可極薄）；格式未 lock |
| 職業／Skill 專欄 | **無**（非 32 名單內） |
| NL 調策略 | D11 lock 未定義；D12 範圍增量新增經營動作 |

### 3.2 影響（對齊範圍增量驗收）

- **職業＝Skill**：服務與策略包裝；必須可表達**能力、適用情境、限制**（D12-1 三欄可被指出）。
- NL 調策略＝經營動作，**≠** 參數／prompt 工具箱主體驗。
- NL 調整若通過限制檢查 → 產生**新** `strategy_version`，再綁**下一約**（本約仍不可熱改）。
- 越權請求：拒絕派出，或拒絕產生新 `strategy_version`（可改寫回界內後再產版——產品體驗；規則側要求邊界仍成立）。
- 非工具箱：不得讓 NL 直接寫入可突破 `constraint_snapshot` 的參數。

### 3.3 `constraint_snapshot`／`strategy_version` 擴展語意（建議採）

| 欄位 | 擴展語意（不改欄名、不改必填狀態） |
|---|---|
| `strategy_version` | 綁定「職業／Skill 包裝下的策略配置版本」。NL 通過限制檢查 → 新版本；未通過 → 不產版。 |
| `constraint_snapshot` | 派出當下快照**職業限制**：至少涵蓋能力邊界、適用情境、禁區（對齊三欄）。結算閘：非空；可稽核「本約策略未越權」。 |

不可洗白：歷史契約之 `constraint_snapshot`／`strategy_version` **禁止**事後改寫以洗白越權。

### 3.4 候選新欄（未 lock）

| 候選 | 狀態 | 說明 |
|---|---|---|
| `profession_id`／`skill_id`（或合併 `profession_skill_id`） | **建議後補選填** | 便於索引／展示／與 Agent 主檔對齊；**是否升必填待 Mack 裁定** |
| 本輪進 32 | **否**（除非 Mack 另 lock） | 三欄語意可先落在 `constraint_snapshot` |

### 3.5 結算閘／拒絕規則

| 時機 | 規則 |
|---|---|
| 派出閘 | `constraint_snapshot` 非空；含職業限制三面向（能力／情境／禁區）可稽核結構；`strategy_version` 非空且對應配置未越權 |
| NL 調策略 | 越權 → 拒絕新 `strategy_version`（或擋寫入）；不得寫入可突破快照邊界之參數 |
| 結算閘 | 快照仍在；可抽查策略未越權；`is_official` 不得建立於已洗白／空快照 |
| 歷史 | 禁止覆寫舊約快照／版本以「補證」合規 |

### 3.6 對 D11 lock 建議

| 動作 | 判定 |
|---|---|
| 改 32 必填名單 | **否**（本輪） |
| 擴展規格說明 | **是**（語意擴展；待准後併入） |
| 候選新欄升必填 | **待 Mack 裁定** |
| `constraint_snapshot` 最小 schema 寫死 | **待 Mack 裁定**（建議先行為約束＋擴展說明） |
