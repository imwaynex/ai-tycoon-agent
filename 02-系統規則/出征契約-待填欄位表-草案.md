## 連動提示（改一處要想）

1. 改時窗／時長 → 狀態機強制結算、60 秒節奏、`actual_duration`。  
2. 改模擬源最小鍵 → 重播、`evidence_id`、`replay_ok`、戰報標示。  
3. 改 `result_status`／`failure_class` → 不可洗白展示、成長計入、敘事槽。  
4. 開 `cancel_supported` → 轉移、正式結果是否產出、出征感（本輪鎖 false）。  
5. 動 `is_official` 閘 → 戰績牆、成長錨定、禁假戰績。  
6. 動 `parallel_dispatch_allowed` → Agent 忙碌拒絕、帝國首頁狀態（本輪鎖 false）。

## 爭議點對齊 D11 決議

1. **短征／計劃時長**：D11 採納短征（同輪體驗內可見歸來；允許壓縮／加速模擬；戰報仍標模擬源）。`planned_duration` 欄位已 lock；**秒數與 grace 仍後補**，不寫死舊閉環數值。  
2. **失敗態建模**：D11 決議——失敗態併入 `result_status`；`failure_class` **非必填**（可不實作）。細枚舉名仍後補。  
3. **取消路徑**：D11 決議——`cancel_supported=false`；不做作戰中取消入口。
