## 切片邊界
### 必做
1. 預置 `WOLF`
2. 一鍵出征 → `in_progress` → settle 歸來
3. 戰果可講欄位展示
4. 戰績牆：最近 settle 可回看
5. 三屏狀態機
6. `real_trading=false`；模擬源標紅可見
7. 結算只認引擎 `BattleResult`；同 `sandbox_run_id` 重放數字必須一致

### 本切片不做（寫死，不是未定）
- 信用／經濟／競技榜 UI 與公式（含 `score` 不顯示）
- K 線、手動下單、Agent 工具箱
- 經營者中途取消（無 `cancelled` 路徑）
- 真實資金
- 完整賽季、公會、多 Agent 組隊

---

## 硬約束
- 模擬盤強制；禁止虛構經驗值；禁止 Agent 自報績效。
- 結算只認引擎輸出。同 `sandbox_run_id` 重放必須同一 `realized_pnl`／`return_pct`；否則結果不得進戰績牆正式列（標失格／不可展示為正式戰果）。

## 1) 戰果怎麼算
### 指標（本切片）
- primary：`realized_pnl`（`sandbox_USD`）
- 並列展示：`return_pct`、`max_drawdown`、`trade_count`
- `win_rate`：可算可不顯；不擋閉環
- **`score`：本切片不計算、不顯示**

### 數據源（強制）
- `market_feed_id` + `sandbox_run_id` + `market_feed_version`
- UI 模擬源標紅可見（文案／badge 由體驗／敘事嵌）

## 2) 時長／失敗態／不可派
### 時長
- `planned_duration_sec`：任務模板寫死（建議預設 **300**；可配 60–3600）
- `in_progress` 不可重派同一 Agent
- 到點強制 settle（即使無單）

### status 枚舉（本切片）
| status | 含義 | 本切片 |
|--------|------|--------|
| `completed` | 正常結算（含虧損） | 做 |
| `failed_risk_breach` | 觸及 risk_limit | 做 |
| `failed_timeout` | 引擎未在 grace 內交付 | 做；grace **標紅** mock 30s |
| `failed_data` | feed／sandbox 失敗 | 做 |
| `failed_constraint` | 違反 Agent 約束 | 做 |
| `cancelled` | 經營者取消 | **不做** |

### 不可派（reject）
| 條件 | 本切片 |
|------|--------|
| `agent.status != ready` | 做 |
| 已有 active mission | 做 |
| `mission.stake > empire.available_stake` | 做（stake＝模擬籌碼） |
| sandbox 不健康 | 做 |
| `min_credit` 門檻 | **標紅**；mock **不擋** |
| `cooldown_sec` | **標紅**；mock **0／不擋** |

## 3) BattleResult 必填
### identity
`result_id`, `mission_id`, `agent_id`, `empire_id`, `created_at`, `settled_at`

### run
`sandbox_run_id`, `market_feed_id`, `market_feed_version`, `planned_duration_sec`, `actual_duration_sec`

### outcome
`status`, `realized_pnl`, `return_pct`, `max_drawdown`, `trade_count`, `currency`

### attribution（最低可稽核；可先 mock URI／快照）
`decision_log_ref`, `constraint_snapshot`, `skill_ids_used[]`

### risk
`risk_limit_snapshot`, `breach_code`（可空；失敗態建議有值）

## 4) 可講／不可講
### UI／戰報可講
`status`, `realized_pnl`, `return_pct`, `max_drawdown`, `trade_count`, `actual_duration_sec`, `breach_code`（失敗時）

### 不可當劇情編造
- `sandbox_run_id`／feed 版號：只可標「可重播／可稽核」
- `decision_log_ref`、`constraint_snapshot` 細節、`skill_ids_used`：無實值勿寫進文案
- 信用／經濟／`score`／競技榜：本切片一句都不寫

## 5) 戰績牆
- 輸入：僅本帝國「玩家出征後引擎 settle」的 `BattleResult`。
- 零次出征 → 空態（敘事槽⑥）。**禁止**開場預置未出征產生的 mock 戰果當正式牆。
- N = 有紀錄時回看上限（N **標紅**；有紀錄後 mock 可顯示 ≥5）。N 不是「進場先塞五筆」。
- 成長對照：第二次（含）settle 之後用真實兩筆並列即可，不靠預置牆。
- 重放不一致／失格結果：不得進正式牆（或進牆但標失格——實作選一，須一致）

## 標紅未定（不擋本切片閉環）
- `failed_timeout` grace 最終值
- `min_credit`／`cooldown` 數值（mock 不擋）
- 戰績牆 N
- 真實資金路徑（Wayne）
- 多標的／時段規則
- 競技場／信用／經濟（見範圍定稿「最小切片」；**本閉環切片不做**）

## 驗收對齊
閉環成立＝可走通出征與歸來（含虧損／失敗態）。  
演示 happy path 對齊 60 秒句「賺了錢回來」。
