## A. 期間屬單次契約（D12-2）

1. `time_window_type`／`planned_duration` 為**本契約實例**欄位。  
2. 同 Agent 多次出征，各約期間**可不同**。  
3. **禁止**帝國級或 Agent 級鎖死單一固定期間。  
4. 派出前（`ready`）：可選／重設本約期間。  
5. 進入 `in_field` 後：本約期間**不可熱改**（同 `strategy_version`）。  
6. 再派＝新契約：新約可重新選期間。  

### 結算閘（期間）

- 檢查本契約時窗／計劃時長存在且合法。  
- 重播使用本契約時長鍵。  
- 壓縮模擬不得改寫已結算契約之計劃時長／時窗欄位值。  

### 驗收對照

同 Agent 兩次出征可有不同 `planned_duration`／時窗；派出前可選／重設。

## B. 職業＝Skill 與 NL 限制（D12-1／D12-1b）

1. 職業＝Skill：策略包裝；須表達**能力、適用情境、限制**。  
2. `strategy_version`：綁定「職業／Skill 包裝下的策略配置版本」。  
3. NL 調策略通過限制檢查 → 產生**新** `strategy_version` → 綁**下一約**；本約不可熱改。  
4. `constraint_snapshot`：派出當下必須快照職業限制；**最小鍵（D13 寫死）**：`ability`、`applicable_context`、`limits`；結算閘要求非空且三鍵可稽核「策略未越權」。  
5. NL 輸入**不得**直接寫入可突破 `constraint_snapshot` 的參數。  
6. 越權：拒絕派出，或拒絕產生新 `strategy_version`（改寫回界內後方可產版）。  
7. 歷史契約之 `constraint_snapshot`／`strategy_version` **禁止**事後改寫洗白。  
8. 仍互斥：NL ≠ 參數／prompt 工具箱主體驗。  

### 候選欄（本附錄不 lock）

`profession_id`／`skill_id`（或 `profession_skill_id`）：**後補選填、本輪不升必填、不進 32**（D13-R1）。

### 驗收對照

- 能力／適用情境／限制三欄可被指出（經快照或展示對齊快照）。  
- NL 調策略不得破職業限制；越權被擋或改寫回界內。
