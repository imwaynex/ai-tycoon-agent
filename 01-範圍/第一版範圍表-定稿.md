# 第一版範圍表（定稿）
負責人：Tycoon 產品主編  
狀態：定稿（可被下游依賴）  
更新：2026-09-15

## 硬標準
60 秒驗收句成立：沒看過產品的人能說——「我有一座 AI 交易帝國，我剛派 WOLF 出去，它賺了錢回來。」

北極星：持續派 AI 出征（不是交易量）。  
身份：AI 帝國經營者，不是手動交易員。  
Agent：出征、作戰、歸來、帶回戰果——不是聊天回覆。

## 做（只含第一版）
- 帝國首頁：一眼知道在經營 AI 交易帝國
- 具名 Agent：至少 `WOLF`（可被派出的角色）
- 出征閉環：出征 → 作戰中 → 歸來 → 帶回戰果
- 戰果可讀：這次賺／賠多少（真實績效語彙）
- 戰績牆：最近幾次出征可回看
- 成長最小切片：錨定真實績效（禁止虛構 XP 當核心）；信用／定價可極薄或後補
- 競技最小切片：最薄對照／排行即可（不做完整賽季）
- 資產大陸先鎖「交易」；標的砍到能演示

## 不做
- 複雜公會／社交組織
- 完整開放經濟、大量資產種類
- 過度自由的 Agent 創建器
- 遊戲化換皮（虛構 XP、任務清單當成長主軸）
- 純競賽平台（沒有出征經營感）
- Agent 工具箱（設定面板／提示詞編輯器當主體驗）
- 手動下單當主路徑

## 五感驗收（全部要過才算第一版）
| 五感 | 驗收檢查 |
|---|---|
| 角色感 | 玩家能叫出 WOLF 的名字與定位；它像角色，不像功能按鈕 |
| 出征感 | 點一次就能派出；狀態清楚是「在外作戰／已歸來」 |
| 戰績感 | 歸來後立刻看到這次戰果數字與一句可說的結果 |
| 成長感 | 至少兩次出征後看得出績效差異；成長話術錨定真實成績 |
| 競技感 | 能看到與他人／他 Agent 的最薄對照，想再派一次 |

60 秒動線必須串通：進場認帝國 → 認識 WOLF → 派出 → 看作戰／歸來 → 看到賺錢回來 → 想再派。

## 定稿後接手順序
1. 系統規則 ＋ 世界敘事：並行
2. 體驗設計：60 秒魔法動線驗收
3. 工程實作：可演示最小閉環
4. 產品主編：用 60 秒驗收句收斂
