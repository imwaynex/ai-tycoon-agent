## 過線（產品預檢／工程落地必勾）

| # | 驗收句 | 失敗訊號 |
|---|--------|----------|
| R1 | 派出後可隨時撤回 | 出征中無撤回；或仍寫「派出後不能叫回」當唯一說明且無撤回鈕 |
| R2 | 撤回＝立刻結算並帶回戰報 | 撤回後無戰報；或戰報不入出征紀錄；或記錄被刪 |
| R3 | 出征前可調策略 | 派出前只能看「會什麼」、無法改打法／策略 |
| R4 | 調策略不破職業限制 | 越權未被擋／未改寫回界內 |
| R5 | 派出頁無出征紀錄 | 派出屏仍有紀錄區塊／緊湊牆 |
| R6 | 戰報頁無角色／策略調整 | 戰報屏仍有改打法／NL／調職業 |
| R7 | 玩家 UI 無「模擬」標 | L0／主路徑仍見「模擬」徽章或腳註（開發詳情除外） |
| R8 | 底層仍模擬盤 | 為去標而接真資／OKX／改 D2／D3 |
