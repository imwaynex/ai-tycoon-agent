## 硬標準（D6）
60 秒驗收句成立：沒看過產品的人能說——  
「我養自己的 AI 交易員：部署 → 模擬出征 → 看戰報 → 決定再派或撤回。」

且小樣本測試出現**自願再派**意願。  
單獨「好玩」或「閉環可跑」不足。

## 一句產品
玩家自行部署策略 Agent → 模擬出征 → 戰報履歷 → 續用／撤回。  
自建引擎；OKX 僅參考。成長＝證據變多；歷史不可洗白。

## 垂直主路徑（只打通這一條）
**任命 → 派出 → 歸來 → 再派（或撤回）**

## 做（第一版）
| 塊 | 必須有 | 驗收句 |
|---|---|---|
| 部署／任命 | 玩家能完成「第一員」策略 Agent 部署（最小步，非工具箱） | 能說出「這是我養的交易員」 |
| 出征契約 | Agent／策略版本、模擬本金與期間（或結束條件）、約束欄位（可極薄）、狀態：可派／出征中／已歸來 | 一次出征邊界清楚 |
| 模擬出征 | 自建模擬盤；戰報標模擬源 | 不承諾真資下單 |
| 歸來戰報 | PnL、回撤、交易次數等真實績效語彙＋模擬標示 | 看完能說這次賺／賠多少 |
| 戰績牆／履歷 | 歷史出征可回看；失敗保留 | 履歷變厚＝成長可見 |
| 下一步 | 續用（再出征）／調整／撤回（停用此配置） | 決策落在續用或撤回，不是逛榜 |

## 不做（本輪硬砍）
- 接 OKX API／真資／跟單／訂閱經濟
- 虛構 XP、等級、任務清單當成長主軸
- 排行榜／純競賽當主畫面
- Agent 參數工具箱／提示詞編輯器當主體驗
- 賽季重置清歷史（洗白）
- 招募市場／雇佣他人 ASP（第一版玩家＝自建自養）
- 對齊或加碼舊「出征閉環」未定稿線

## 五感驗收（全新口徑）
| 感 | 檢查 |
|---|---|
| 任命感 | 像招募／任命大將，不像打開設定面板 |
| 出征感 | 一鍵派出；狀態清楚「在外／已歸」 |
| 戰報感 | 歸來立刻看到可說的數字＋模擬源 |
| 履歷感 | 至少兩次出征後看得出證據變厚；失敗仍在 |
| 再派感 | 看完想再派或明確撤回，不是離開 |

## Go／No-go
- **Go**：60 秒句成立 **且** 自願再派有紀錄
- **No-go**：只有演示可跑、或只有喜歡角色、或聽起來像工具箱／跟單圍觀

1. **系統規則**：出征契約欄位表＋狀態機＋不可洗白（欄位未 lock 可先骨架＋待填）
