## 畫面狀態
| UI 狀態 | 條件 | 主 CTA |
|---------|------|--------|
| 首屏空態 | 尚無 Agent | 收下 WOLF（占位） |
| 首屏可派 | 有 WOLF 且無 active mission | 出征 |
| 首屏不可派 | 不可派枚舉任一成立 | disabled＋文案槽②＋原因 |
| 出征中 | mission in_progress | 無（等戰報；v1 無取消） |
| 歸來成功 | status=`completed` | 看戰績／再出征 |
| 歸來失敗 | status=`failed_*` | 看戰績／再出征 |
| 戰績空態 | 尚無 settle 紀錄 | 文案槽⑥ |

## 轉換
`首屏可派` --出征--> `出征中` --settle--> `歸來` --回首屏--> `首屏可派`  
分支：出征前 reject → 停留首屏不可派。
