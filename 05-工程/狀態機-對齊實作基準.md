## 畫面狀態
| UI 狀態 | 條件 | 主 CTA |
|---------|------|--------|
| 首屏空態 | 尚無 Agent | 收下 WOLF（本切片預置，通常跳過） |
| 首屏可派 | WOLF ready、無 active mission | 出征 |
| 首屏不可派 | 不可派枚舉（不含 min_credit／cooldown） | disabled＋槽②＋原因 |
| 出征中 | in_progress | 無取消 |
| 歸來成功 | status=`completed` | 再出征／戰績牆 |
| 歸來失敗 | status=`failed_*` | 再出征／戰績牆＋breach_code |
| 戰績空態 | 無 settle | 槽⑥ |

## 轉換
首屏可派 --出征--> 出征中 --settle--> 歸來 --再出征--> 首屏可派

## mock 引擎（標紅）
- 演示等待可縮 2–4s；`planned_duration_sec` 仍寫模板值（建議 300）
- 完整 BattleResult；UI 只渲染可講欄位
- happy path 偏向 `completed`＋正 pnl（驗收句）；失敗態可走通
- 同 `sandbox_run_id` 重放 → 同 realized_pnl／return_pct
- 戰績牆 mock ≥5；失格／重放不一致不進正式牆
