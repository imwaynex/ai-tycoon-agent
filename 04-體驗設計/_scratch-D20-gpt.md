A. 一句話：D20 後主路徑

任命大將 → 在角色側按需調打法（受 Skill 限制）→ 派出頁選期間並派出 → 出征 → 歸來／撤回結算 → 戰報 → 回角色側調打法 → 再到派出頁選期間並派出。

調打法是出征前的可選步驟；再派不必重新任命，也不強迫每次修改策略。

首輪首屏不新增 NL 框；其他屏位也不因 D20 新增 NL 能力。

D. 關鍵路徑與禁止路徑

首次派出

1. 任命席完成任命。
2. 進入大將已就位態，看見目前打法。
3. 按需進入「改打法」；儲存後回大將。
4. 點「前往派出」。
5. 選期間，點「派出」，進入出征中。

歸來／撤回後調整再派

1. 歸來，或在出征中撤回並完成結算。
2. 查看戰報；撤回情況保留 withdrawn_settled。
3. 點「回大將準備再派」，回到該大將的結果摘要與策略區。
4. 點「調整打法」，在角色側修改並儲存。
5. 回大將，點「前往派出」。
6. 重新選期間，點「派出」。

沿用打法者可在第 3 步後走次級導覽，直接前往派出選期間。

禁止路徑

- 派出選期間 → 改打法／NL → 同屏派出。
- 戰報 → 直接修改或儲存策略。
- 出征中 → 修改策略，包含從角色側繞入。
- 撤回尚未結算 → 調策略或再派。
- 「儲存打法並派出」一次提交兩種語意。
- 再派必須先重新任命。
- 改打法後覆寫、隱藏或重新歸因既有戰報。

E. 歸來／撤回後「調策略 → 再派」的具體 UI 解

建議把引導分成兩站：戰報負責回大將，大將負責看見並修改打法。

| 位置 | 直屏排列／文案槽 | CTA 層級與行為 |
|---|---|---|
| 戰報首屏 | 狀態 → [本次結果摘要] → 結果／證據 | 不放策略操作 |
| 戰報操作區 | 輔助文案：「回到大將，可調整打法後再出征。」 | 主導覽「回大將準備再派」；返回該角色的策略摘要區，不自動進編輯 |
| 大將歸來態首屏 | [歸來／撤回已結算] → [本次結果摘要] →「目前打法」卡 | 策略卡緊接結果摘要，讓結果與下一步相鄰 |
| 大將歸來態操作區 | 「調整打法，準備下次出征。」 | 主導覽「調整打法」；次級文字導覽「沿用打法，前往派出」 |
| 策略編輯屏 | 目前設定 → 可調項目 → Skill 限制 | 唯一提交 CTA「儲存打法」；返回不儲存 |
| 儲存成功後的大將頁 | 提示「打法已更新」；展示更新後摘要 | 主導覽改為「前往派出」 |
| 派出 ready | 標題 → 期間選擇 → 底部操作 | 唯一提交 CTA「派出」 |

補充落地規則：

- 上述「調整打法」與「前往派出」都是導覽；實際提交分別發生在策略編輯屏與派出屏。
- 不依「損益不佳」新增判定門檻；所有已結算歸來態都可提供相同入口。
- 「打法已更新」只確認儲存成功，不宣稱表現改善。
- 不可達時不跳轉；依既有規則顯示原因，不新增解鎖條件。

G. 驗收句草稿｜待 Cruz lock

- **待 Cruz lock：**使用者只能在任命完成後的角色側、且角色不在出征中時修改打法；可調項目仍受既有 Skill 限制。
- **待 Cruz lock：**派出 ready 僅承擔期間選擇與派出，不含改打法入口、NL 或紀錄。
- **待 Cruz lock：**歸來戰報與 withdrawn_settled 戰報皆可返回對應大將，並清楚看見調整打法的下一步；戰報本身不可調整。
- **待 Cruz lock：**歸來／撤回已結算的大將可調整後再派，也可沿用打法再派，兩者皆不以重新任命為前置。
- **待 Cruz lock：**策略儲存與派出是分開的提交；儲存策略不會自動派出。
- **待 Cruz lock：**出征中及撤回尚未結算時，不可透過頁面、舊連結或提交請求修改打法或再派。
- **待 Cruz lock：**所有相關 L0 最多兩行；首輪首屏無 NL 框；不可達目的地不執行跳轉。
- **待 Cruz lock：**策略修改不改寫過往戰報、撤回結算身分或履歷證據；既有去「模擬」標要求維持。

H. Anti-jobs

- 不重做 D18 全案；只收斂策略屏位與再派銜接。
- 不增加策略種類、Skill 能力、商業範圍或成效承諾。
- 不把派出頁、戰報或出征中變成策略工具箱。
- 不新增即時盯盤、OKX 或真資主依賴。
- 不把重新任命包裝成唯一的策略優化方式。
- 不以改策略洗掉虧損、撤回或其他歷史證據。
- 不自動判定使用者「應該改打法」，也不自動代改。

|---|---|---|

| 清晰度 | 使用者分得清儲存打法與正式派出 | 儲存後詢問「現在是否已出征？」；[正確理解標準待填] |
| 再派意願 | 結果摘要緊接策略區，能讓使用者形成下一次出征的理由 | 詢問是否願意再派及原因；[意願判讀方式待填] |
| 再派意願 | 保留「沿用打法」能避免不想修改者中斷再派 | 觀察沿用路徑的選擇理由與完成情況；[判讀標準待填] |
