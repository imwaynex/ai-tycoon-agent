## 驗收
兩次真實出征後，玩家能用數字指出「這次比上次好／差在哪」，仍想再派。  
截圖：同一隻 WOLF、兩次 BattleResult、不是發 XP。

## 版位裁決（規則標紅項 → 體驗定）
| 項 | 裁決 |
|----|------|
| 對照主出現點 | **③ 歸來屏**：當 `curr` 剛 settle 且牆內已有 ≥2 筆時，在戰果六欄下方展開「兩次對照」區塊 |
| 次出現點 | **戰績牆**：≥2 筆時，牆頂或最新兩筆旁可展開同一對照（同一 `GrowthCompare`） |
| 不出現 | 首屏主 CTA 區、獨立「成長中心／等級頁」——那像控制台 |
| G2／G3 | **預設顯示**：`verdict=better/worse` 時，G1 數字必顯，其下可套 G2／G3 一句；`flat`／`none` 只顯 G1 或 G0 |
| trade_count | 進對照列（上次／這次），**不**參與更好／更差語氣 |

## 狀態 × 文案
| 正式牆筆數 | UI | 文案 |
|------------|-----|------|
| 0 | 戰績牆空態 | G4／槽⑥ |
| 1 | 牆有一筆；歸來不開對照 | G0 |
| ≥2 | 歸來＋牆可開對照 | G1 必顯；G2／G3 依 `verdict` |

## 對照區塊資訊架構
1. 標題：同一隻 WOLF · 兩次出征  
2. 上次／這次並列：`realized_pnl`、`return_pct`、`max_drawdown`（＋`trade_count`）  
3. 差在：`delta_*` 三欄（引擎值）  
4. 可選一句：G2 或 G3  
5. 固定句錨點可見：「成長看戰績，不看經驗值」（可收在 G1 末句）  
6. 次 CTA：「再出征」

## 空牆紅線（必須落地）
- 首次進場／零次 settle＝空牆；禁止預置 mock  
- 對照原料只能是本帝國 WOLF 引擎 settle  

## 紅線（體驗）
- 禁止 XP／等級條／徽章／信用分／單一「成長分」  
- 禁止無數字的「變強了」  
- 禁止做成排行榜／訂閱／圍觀（B 刀）  
- 禁止把對照做成交易報表控制台（多圖表、可鑽 K 線）

## 像世界還是像控制台｜自檢
**過關**：歸來像戰報附「兩次征途對讀」；牆像帝國史。  
**不及格**：等級頁、進度條、雷達圖綜合分、主畫面變分析台。

## 動線（疊加在 60 秒之後）
1. 首次：空牆 → 出征 → 歸來（無對照，G0 可在牆／卡提示）  
2. 再派 → 第二次歸來 → **對照區塊出現** → 說得出好／差 → 再出征
