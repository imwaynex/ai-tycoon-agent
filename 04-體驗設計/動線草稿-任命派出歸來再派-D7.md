## 2. 最小 IA（三屏＋一牆）

主路徑只暴露四個經營節點；其餘進「更多／履歷細節」不擋主線。

```
[屏1 任命席] ──部署完成──► [屏2 出征席] ──派出──► (出征中態)
                                      │
                                      ▼ 歸來
                               [屏3 戰報席] ──再派／調整／撤回──► 回屏2或屏1
                                      │
                                      └──條目入──► [牆 戰績履歷]（可從屏1／3進入）
```

| 屏／牆 | 經營者一句話 | 主行動 | 禁止出現在主層 |
|--------|--------------|--------|----------------|
| 1 任命席 | 「這是我要養的大將」 | 任命／收下第一員 | 參數矩陣、prompt 編輯器、API／Model 旋鈕、K 線 |
| 2 出征席 | 「一鍵派出去」 | 派出（可派時） | 逐筆下單、即時 tick 操盤、跟單按鈕 |
| 3 戰報席 | 「這次賺／賠多少，然後呢」 | 再派／調整／撤回 | 排行榜勾引、XP 升級、洗白失敗 |
| 牆 戰績履歷 | 「證據變厚了」 | 回看歷史（含失敗） | 賽季清歷史、假徽章當成長 |

**狀態與畫面（最小可講；枚舉待系統規則 lock）**

| 狀態（義位） | 落在哪 | 畫面要說清 |
|--------------|--------|------------|
| 尚無大將 | 屏1 空態 | A0 |
| 可派 | 屏2 | A2＋派出主鈕 |
| 出征中 | 屏2（或輕覆層） | B1；主鈕變「等待戰報」；禁盯盤 |
| 已歸來 | 屏3 | C0 或 C1 |
| 已撤回配置 | 屏1／2 標記停用 | 履歷仍在 |

選中／無選中類差異：**不**用多套導航；本輪無城市場景需求。若日後有帝國大廳，主 CTA 仍必須是任命／派出／再派，不是逛功能表。

## 3. 動線逐步（對齊敘事槽）

### 3.1 任命（屏1）← 槽 A

**空態（A0）**  
- 文案：帝國還沒有大將／先任命第一員。  
- 主鈕：`任命第一員`（或等價）。  
- 次要：無（避免「先去設定」）。

**任命卡（A1）**  
- 可見：`{agent_name}`、`{role_line}`、盤別＝**模擬**（常駐標示）。  
- 主鈕：`收下／任命`。  
- 不展開：技能樹、參數表、提示詞。

**完成（A2）**  
- 短回饋：已就位、模擬盤就緒、可以派出。  
- 自動或一鍵進入屏2。

**不可派（A3）**  
- 顯示 `{fail_reason}` 占位；主路徑改為「調整條件」或等待——**不**打開工具箱當預設解法。

### 3.2 派出（屏2）← 槽 B

**出征確認（B0）**——一鍵前的最小契約層（欄位未 lock，只露可講集）

| 展示（義位） | 占位 | 備註 |
|--------------|------|------|
| 大將 | `{agent_name}` | 必顯 |
| 策略版本 | `{strategy_version}` | 待 lock；無則標「待對齊」 |
| 模擬本金 | `{sim_capital}` | 待 lock |
| 期間／結束 | `{duration_or_end}` | 待 lock；體驗須能服務 60 秒節奏（時長折衷升級產品主編） |
| 約束極薄 | `{constraint_brief}` | 可空；空是否允許派出 → 規則待 lock |
| 模擬源 | `{sim_badge}` | **常駐可見** |

- 主鈕：`派出`（出征感）。  
- 次鈕：無或 `返回`。  
- 確認句語氣：派出之後等戰報——別盯盤。

**出征中（B1）**  
- 狀態條：`出征中`＋`{elapsed}`。  
- 主區：等待／可回看「這次出征進行中」卡片；**不**提供下單、改單、行情深度圖。  
- 可進履歷牆看歷史，但本次未歸前屏3不開完整決策席。

### 3.3 歸來（屏3）← 槽 C

**成功結算含虧損（C0）**  
必顯可講績效（無引擎數值時整屏標「示意」）：

- `{realized_pnl}` · `{return_pct}` · `{max_drawdown}` · `{trade_count}` · `{elapsed}`  
- `{sim_badge}`  
- 一句：一筆可稽核戰績，已記入履歷。

**失敗／折返（C1）**  
- `{fail_reason}`；失敗仍入牆；禁洗白。

**空牆（C2）**——僅當無任何歷史且誤入牆時。

### 3.4 再派（屏3 決策席）← 槽 D

主區三選一（D0），權重清晰：

| 行動 | 語意 | 去向 |
|------|------|------|
| **再派／續用** | 同一配置再走一趟 | 回屏2，可帶 `{parent_contract_id}` 義位（欄位待 lock） |
| **調整後再派** | 改約束或版本——**薄層**，不是參數工廠 | 短調整片 → 屏2；禁止落到全量工具箱 |
| **撤回** | 停用此配置；履歷不刪 | 回屏1／2 標記停用 |

一筆時用 D2 提示：再派一次才看得出變強／變弱。  
兩筆以上可露出 D3 對照入口（delta 公式待規則／工程）。

## 4. 五感自檢（本草案）

| 感 | 本動線怎麼過 | 風險 |
|----|--------------|------|
| 任命感 | 屏1 卡面＋收下，無設定面板開場 | 工程把部署做成 wizard 多步表單 |
| 出征感 | 屏2 單一派出主鈕；出征中禁盯盤 | 時長過長導致玩家去找 tick |
| 戰報感 | 屏3 數字＋模擬標＋入履歷 | 假數未標示意 |
| 履歷感 | 牆保留失敗；再派加厚 | 撤回誤刪歷史 |
| 再派感 | 決策席三選一；再派為暖／主 CTA | 主 CTA 做成「去排行榜」 |

喜歡度／清晰度／再派意願：**分開記**（產品小樣本）；本檔不替代測試。

## 5. 給工程的交接重點（不猜未 lock 欄）

1. 路由／狀態機畫面映射：空態→可派→出征中→已歸來→（再派｜調整｜撤回）。  
2. 模擬源 UI 常駐；無數據禁止填假數，用「示意」或空態。  
3. 戰績牆：正式列與失敗列皆可回看；撤回不停展示歷史。  
4. 「調整」第一版只允許極薄字段（與規則 lock 的約束鍵對齊）；其餘藏進非主路徑。  
5. 禁止入口：K 線主屏、API 設定、prompt／Model 旋鈕、排行榜主屏、XP。

文案嵌槽：直接引用 `文案槽-任命出征歸來再派-D7-待定稿.md` 之 A0–D3；數字由引擎填占位。

## 6. 驗收（體驗側可測草稿）

**60 秒口述腳本（給產品主編）**

1. 打開屏1 → 能指認「要任命的大將」→ 任命。  
2. 屏2 → 能說出派出邊界（本金／期間等可見占位）→ 派出。  
3. 出征中 → 能說「在外面等戰報」而非「我在交易」。  
4. 屏3 → 能說賺／賠多少（或示意）＋模擬 → 選再派或撤回。

**草稿通過（非產品 Go）**：旁觀者能複述產品驗收句；五感無紅線項。
