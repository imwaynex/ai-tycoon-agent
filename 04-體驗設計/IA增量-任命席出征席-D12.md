## 1. 任命席（屏1）— 焦點＝角色本身

### 1.1 主層（預設 Tab：角色）

經營者一眼要判：「這員是誰、職業會什麼、綜合表現如何、要不要養／派出」。

| 區塊 | 內容 | 規則 |
|------|------|------|
| 角色頭 | `{agent_name}`、可選立繪／頭像、模擬源常駐標 | 主角感；非空白工具頁 |
| 職業＝Skill | **能力**／**適用情境**／**限制** 三欄（短句） | D12-1 必露；資訊架構露出，不是參數表 |
| NL 調策略入口 | 次級按鈕如「用一句話調整策略」 | 可標入口；點進薄層對話／單行指令；**必須提示受限於職業限制**；禁止落到參數工具箱／prompt 編輯器主體驗 |
| 綜合表現 | 匯總卡：例如累計 PnL／近 N 次勝率或報酬區間／最大回撤摘要／出征次數（欄位名跟戰報／牆對齊；無數據標示意或空態） | 經營者一眼可判；**不是**歷史清單 |
| 主 CTA | 未任命：`任命／收下`；已可派：`去出征席` 或 `派出` | 任命感 |
| 次 CTA | `撤回此配置`（已任命時） | 履歷不刪 |

**禁止主層**：完整歷史列表、K 線、API／Model 旋鈕、技能點數／XP。

### 1.2 子分頁：歷史紀錄

- 入口：任命席內 Tab「歷史」或「戰績明細」（次級）。  
- 內容：戰績牆條目列表（含失敗）；點進單次戰報。  
- 空態：嵌 C2。  
- 與「牆 戰績履歷」可同資料源；任命席歷史是**入口裁切**，牆仍可獨立進。

### 1.3 空態（尚無大將）

維持 A0；主層只有任命 entice＋任命 CTA；職業三欄在選角／任命卡上露出第一員 Skill。

## 2. 出征席（屏2）— 每次可換期間

### 2.1 派出前（可派／B0）

| 區塊 | 內容 | 規則 |
|------|------|------|
| 大將摘要 | 名＋職業名（Skill）一行 | 連回任命席角色 |
| **出征期間** | `time_window_type`＋`planned_duration`（或結束條件若產品開） | **每次出征可改**；預設可帶上次，但必須可重設；不得鎖死全帝國單一期間（D12-2） |
| 本金等契約摘要 | `simulation_principal` 等已 lock 必填之可講項 | 短征可壓縮時長；仍標模擬 |
| 約束極薄 | 來自職業限制＋本次約束快照摘要 | 與 NL 調策略結果一致；不可暗示能 NL 越權 |
| 主 CTA | `派出` | 一鍵；`cancel_supported=false` |
| 次 | `返回任命席` | |

期間控件建議（mobile）：
- **直屏**：期間選擇器在派出鈕上方（分段控制或列表：如 短征／日／週——具體選項產品可定，體驗要求「每次可換」）。  
- **橫屏**：期間與契約摘要可左右分欄，主 CTA 仍拇指可及（右下或底欄）。

### 2.2 出征中（B1）

- 顯示：狀態出征中、`{elapsed}`、本次已選期間、模擬標。  
- **無**取消出征按鈕（D11 lock）。  
- 禁盯盤／下單。

### 2.3 與再派連動

再派進入屏2 時：**期間控件重置為可編**（可預填上次，但明示可改）。同 Agent 兩次出征期間可以不同——驗收句。

## 3. 職業＝Skill 露出規格

```
職業／Skill
├─ 能力：會什麼（策略視角一句）
├─ 適用情境：適合什麼行情／任務（一句）
└─ 限制：不能超什麼（硬邊界一句；NL 調策略不可破）
```

NL 調策略薄層：
1. 單行或短對話輸入經營意圖。  
2. 系統回顯「將套用的約束／策略調整摘要」＋重申限制。  
3. 確認後寫入本次／配置快照；越權請求 → 拒絕語氣（敘事槽）＋留在職業內。  
4. UI 不得提供「打開全部參數」捷徑作為主解法。

## 4. Mobile 直／橫準則

| 準則 | 直屏（portrait） | 橫屏（landscape） |
|------|------------------|-------------------|
| 優先 | 預設設計與 60 秒驗收主場景 | 同等可走完主路徑，非裁切殘障 |
| 任命席 | 上：角色；中：職業三欄＋綜合表現；下：主 CTA；歷史＝Tab | 左：角色＋綜合表現；右：職業三欄＋CTA；歷史仍 Tab／抽屜 |
| 出征席 | 上摘要；中期間＋契約；底派出 | 左摘要＋期間；右契約＋派出 |
| 觸控 | 主 CTA ≥ 44pt；期間控件勿藏進溢位選單唯一入口 | 主 CTA 不貼瀏海／手勢條衝突區 |
| Desktop | 後置；自 mobile 欄位衍生加寬，不反向塞手機 | — |
