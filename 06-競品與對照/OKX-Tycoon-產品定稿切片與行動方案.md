## 已鎖定的產品定義

| 項 | 決定 |
|---|---|
| 玩家 | 自行部署策略 Agent → 模擬交易 → 看戰報 → 續用或撤回 |
| 出征 | 模擬盤；真實資金後置；戰報標模擬源 |
| 邊界 | Tycoon **自建**；OKX 只是參考雛形，不做第一版接線依賴 |
| 成長 | 可信證據／履歷變多（非虛構升級） |
| 風險硬規則 | 歷史戰績與失敗紀錄不可洗白 |
| Go／No-go | **60 秒理解成立** 且 **自願再次出征** |

## 一句產品定位
你養自己的 AI 交易員：部署它、派它去模擬戰場、帶戰績回來、決定要不要再派——履歷越厚越可信，歷史不能洗白。

## 出征契約（第一版最小規格）
一次出征必須寫清：
1. 哪個 Agent／哪個策略版本
2. 模擬本金與期間（或結束條件）
3. 約束（標的、槓桿上限等——可極薄，但要有欄位）
4. 狀態：可派／出征中／已歸來
5. 歸來戰報：PnL、回撤、交易次數等＋模擬源標示
6. 下一步：續用（再出征）／調整／撤回（停用此配置）
7. 戰績牆：歷史不可刪、不可賽季洗白
